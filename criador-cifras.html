HarpaCifrada — Editor de Cifras

1. Dados da música

Cole a cifra acima da letra usando espaços. Cada par de linhas vira uma linha musical. Você também pode inserir 1ª estrofe, Coro, 2ª estrofe etc. O programa cria automaticamente cada label. O modo automático tenta converter a posição visual em pos. Depois, no ajuste fino, arraste cada cifra até o ponto exato da letra.
Nenhuma cifra selecionada.
Arrastar: posiciona ← →: ajuste fino Del: remove a cifra

2. Prévia e ajuste fino

No modo AUTOMÁTICO, as posições são estimadas. No modo AJUSTE FINO, clique e arraste as cifras. Elas se encaixam na posição de cada caractere da letra.

3. Código da música

O código agora é editável. APLICAR CÓDIGO leva o que está escrito para as outras telas. ATUALIZAR CÓDIGO faz o caminho inverso: pega o que foi alterado na interface e escreve aqui.
